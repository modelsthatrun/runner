# Security

Please report vulnerabilities privately, through **Report a vulnerability** under this repository's Security tab (GitHub private vulnerability reporting), not in a public issue.

In scope:
- **The submission inbox:** sign-in, tokens, the submission checks and their limits.
- **The `mtr` client:** how it stores credentials and what it sends.
- **Anything that lets a record pass as measured** when it wasn't, beyond editing your own records. The checks are described in [docs/submitting.md](docs/submitting.md).

Out of scope: third-party model code and weights, which `mtr` runs as their official instructions say. Report those upstream.
